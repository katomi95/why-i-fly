# ただ雲は流れて ／ WHY I FLY

### ▶ 遊ぶ： https://katomi95.github.io/why-i-fly/

敗戦間近の、ある架空の国。
特攻を命じられた十代の少年兵と、それを冷静に否定しつづける女性の、五日間の会話劇。

**プレイ時間：約15〜20分**
HTML / CSS / JavaScript のみ。外部ライブラリなし。PC・スマートフォン対応。

---

## 作品について

これは戦争ゲームではありません。戦闘描写・敵の撃破・爆発は一切ありません。

描いているのは、
**一度は死を受け入れた人間に、あとから生きたい理由が生まれてしまう**
という悲劇です。

主人公は最後に出撃しますが、それは「尊い自己犠牲」でも「立派な死」でもありません。
死ぬ理由をすべて失ってなお、過去の覚悟と仲間の死と、自分が生きてきた文脈から
歩き出せなかった人間の話として描いています。

> 人間は、正しいことを理解したからといって、必ず正しい選択をできるわけではない。

登場する国家・軍隊・基地・作戦・人物・兵器はすべて架空であり、
実在の戦争、実在の作戦、実在の組織とは一切関係ありません。

## 遊びかた

画面のどこかをクリック／タップで読み進めます（`Space` / `Enter` も可）。
文章表示中にクリックすると、その行を最後まで表示します。

セーブ・ロード・設定はありません。一度きりの通し読みとして作られています。
左上の `♪` で音の ON / OFF を切り替えられます（音はすべて Web Audio による生成音です）。

意図的な「間」が多く挿入されています。何も起きない数秒は演出です。

---

## WHY I FIGHT

画面の隅には、主人公が自分に言い聞かせている五つの理由が表示されます。

```
WHY I FIGHT
  国を守る
  家族を守る
  仲間との約束
  軍人としての責務
  逃げない
```

会話が進むごとに、これらは一つずつ否定され、取り消し線が引かれていきます。
最後には、何も残りません。

## ファイル構成

```
.
├── index.html   画面構造・立ち絵（インライン SVG）
├── style.css    背景（CSS グラデーション＋SVG シルエット）・UI
├── story.js     シナリオデータ（全 896 コマンド）
└── script.js    進行エンジン・Web Audio
```

背景・立ち絵は画像ファイルを使わず、すべて CSS と SVG で描いています。
画像・音声アセットが 0 なので、そのまま GitHub Pages に置けば動きます。

### 公開

リポジトリの Settings → Pages で `main` ブランチの `/ (root)` を公開すると、
`https://katomi95.github.io/why-i-fly/` で遊べます。
ビルド不要・依存なしなので、リポジトリをそのまま置くだけで動きます。

### ローカルで動かす

```bash
python -m http.server 8231
```

## シナリオ拡張のしかた

`story.js` は上から順に実行されるコマンドの配列です。

| 記法 | 意味 |
|---|---|
| `N('地の文')` | ナレーション（3行まで積み重なる） |
| `R('台詞')` / `I('台詞')` | 主人公リオ／イリスの台詞 |
| `D('話者','台詞')` | その他の人物 |
| `BG('road_eve')` | 背景切り替え（クラス名は `style.css` の `.bg-*`） |
| `CH('iris','cry')` / `CH(null)` | 立ち絵の表示・表情・消去 |
| `W_(1200)` | 間（ミリ秒／スキップ不可） |
| `BIG('DAY 1', 2200)` | 全画面の大文字表示 |
| `CRACK('kuni')` / `STRIKE('kuni')` | WHY I FIGHT に亀裂／取り消し線 |
| `NOTE([...])` | 手紙・紙切れの表示 |
| `CHOICE([...], 5000)` | 制限時間つき選択肢 |
| `SFX('takeoff')` / `BGM('stop')` | 音 |

台詞の第2引数に `{ slow:true }` で表示速度を落とし、
`{ auto:2600, lock:true }` でクリックを受けつけず自動で送ります
（終盤の「行くな」の連続に使用）。
