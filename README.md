# ただ雲は流れて ／ WHY I FLY

### ▶ 遊ぶ： https://katomi95.github.io/why-i-fly/

敗戦間近の、ある架空の国。
特攻を命じられた十代の少年兵と、否定しつづける女性の、五日間の会話劇。

**プレイ時間：約15〜20分**
HTML / CSS / JavaScript のみ。外部ライブラリなし。PC・スマートフォン対応。

---

## 作品について

これは戦争ゲームではありません。戦闘描写・敵の撃破・爆発は一切ありません。

登場する国家・軍隊・基地・作戦・人物・兵器はすべて架空であり、
実在の戦争、実在の作戦、実在の組織とは一切関係ありません。

---

## 遊びかた

画面のどこかをクリック／タップで読み進めます（`Space` / `Enter` も可）。
文章表示中にクリックすると、その行を最後まで表示します。

セーブ・ロード・設定はありません。一度きりの通し読みとして作られています。
左上の `♪` で音の ON / OFF を切り替えられます（音はすべて Web Audio による生成音です）。

意図的な「間」が多く挿入されています。何も起きない数秒は演出です。

---

## WHY I FIGHT

画面の隅には、主人公が自分に言い聞かせている五つの理由が表示されます。

```
WHY I FIGHT
  国を守る
  家族を守る
  仲間との約束
  軍人としての責務
  逃げない
```

会話が進むごとに、これらは一つずつ否定され、取り消し線が引かれていきます。
最後には、何も残りません。
